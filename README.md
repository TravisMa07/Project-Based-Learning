# Project-Based-Learning

A hands-on collection of cybersecurity projects built from the ground up to strengthen practical skills through project-based learning.

This monorepo contains multiple projects organized into tiers based on difficulty, technical depth, and overall complexity. Each project is designed to move beyond theory through hands-on implementation of cybersecurity and software engineering concepts.

## Goals
The primary goals of this repository are to:

- Develop practical cybersecurity skills through hands-on projects
- Improve programming and software engineering skills
- Gain a deeper understanding of how security tools and systems work internally
- Practice researching, designing, debugging, testing, and documenting projects independently

## Learning Philosophy
Every project in this repository is completed by hand **without the use of direct AI coding tools**.

AI may be used as a learning resource for explaining concepts, discussing theory, or helping identify topics to study, but the actual design, implementation, debugging, and code are completed independently.

The goal is not simply to produce working software quickly with AI. The goal is to understand why something works, how it works, how it can fail, and how it can be improved. By building a stronger foundation in cybersecurity and software engineering, I can also use AI more effectively and intentionally in the future.

## Project Structure

Projects are organized into difficulty tiers, with each tier introducing more advanced concepts and requiring greater independence.

- Tier 1 — **Beginner**: Introductory projects with lower complexity and a smaller scope
- Tier 2 — **Intermediate**: Projects with increased complexity, depth, and problem-solving requirements
- Tier 3 — **Advanced**: Highly complex projects involving substantial depth, integration, and independent problem-solving

Each project will contain its own documentation, source code, requirements, and any supporting resources needed to understand and run it.
